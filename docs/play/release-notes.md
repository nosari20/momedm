# Release notes ("What's new") — per-release, EN + FR

Play requires this text for every release; testers see it first. Keep each
under 500 characters.

## 1.0 (versionCode 1)

**en-US**
```
First release: parental control between two phones over Bluetooth — no cloud, no account. Choose your child's apps, set a bedtime the phone keeps by itself, pause with your PIN. Open source.
```

**fr-FR**
```
Première version : contrôle parental entre deux téléphones en Bluetooth — sans cloud, sans compte. Choisissez les applis de votre enfant, fixez une heure de coucher que le téléphone respecte tout seul, suspendez avec votre code PIN. Open source.
```
